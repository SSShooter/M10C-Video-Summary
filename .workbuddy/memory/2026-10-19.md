# 2026-10-19

## siri-glow.html 第四版：种子光球 → 蔓延
- 用户反馈：雾团起点太大（scale .55 ≈ 340px），一上来就铺满，缺"从按钮蔓延开"的因果感。
- 拆两层：新增 `.seed`（120px 暖白亮点，blur 14px，固定在框顶边中点=按钮正下方），动画 0→亮(12% 峰值 .95)→放大下沉化开；`.wave` 雾团起点压到 scale .18，随种子化开同步长大（.18→.55→1.22）再消散。种子动画时长 = wave-duration × .6。
- 要点：方向感/起点用独立小元素（seed）表达，蔓延感用雾团 scale 梯度表达；不要在同一个元素上既要"小亮点"又要"大铺满"。
- 第六版：雾团 scale 1.05 才能盖住 300px 高的框，但之前 55% 后 opacity 就退——刚铺满就消失。改为 50% 铺满、78% 仍保持 .45、最后 22% 才淡出。原则：先铺满再整体消散，铺满和消退不能并行。
- 第五版（用户洞察）：球一旦位移就会被追踪，球走了上半框就显得色彩不饱满。改为全部锚定顶边中点原地扩散——wave 的 top 从 50% 改回 0、translate 恒为 (-50%,-50%)，seed 也去掉 translateY；扩散纯靠 scale（wave .15→1.3，seed .35→1.4）。原则：光源锚定不动，蔓延用缩放表达，顶部全程有光。
