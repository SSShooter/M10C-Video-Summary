# 2026-10-18

## siri-glow.html 光球柔化改造
- 痛点：光球（.wave）生硬、与边框光环脱节。
- 第一版（果冻球）用户仍觉突兀，第二版彻底去"球"化：.wave 改为 2.4×wave-size 的五色极光雾团（橙/红/紫/蓝/粉五个 radial-gradient 错位叠加），blur 默认 56px、峰值透明度仅 0.5；动画不再是位移穿过，而是 ease-in-out 的"渗入—扩散—消散"（translate -62%→-36% + scale .85→1.15 + 轻微 rotate），时长默认 1.4s。
- 新增 @property --boost，光环入场用 m10c-ring-in 亮度脉冲（boost 2→1.4→1）模拟"能量灌入边框"；glow-edge 延迟 0.12s 分层淡入；JS 光环触发 0.45、吐字提前到 waveMs*0.5；删除了 --travel 测量；prefers-reduced-motion 有静态兜底。
- 第三版补回"从按钮冒出来"的方向感：雾团初始 scale 0.55 聚在顶边（按钮正下方）快速显形（14% 到峰值 0.55），随后下沉 + 扩散到 scale 1.22 + 渐淡消散。方向感靠"起点小且亮"，弥漫感靠全程大模糊——两者不冲突。
- 经验：Siri 原版质感的关键是"没有可辨识的物体"——大模糊 + 低透明 + 多色错位 + 缓慢扩散，而非一个运动的光球；方向感用缩放/透明度梯度表达，不用位移轮廓。
