## AI 生成光效（Siri Glow）抽象

参考 `demo/siri-glow.html`，把"光雾 + 六色旋转光环"落到 AI 生成 markdown / 思维导图两个面板上。

- 新增 `components/GenerationGlow.tsx`：封装 4 个图层（wave / seed / ring / edge）+ 状态类时序（`m10c-is-waving` → 45% 处 `m10c-is-ring` → 结束 1.1s 后淡出）。调用方只传 `active` / `streaming`。
- 样式追加在 `assets/style.css` 末尾（所有 entrypoint 都已引入，content script 走 `?inline` 拼接，无需改 4 处 import）。
- 接入点：`SummaryDisplay`（生成中与已有内容共用同一容器，避免 ReasoningDisplay → markdown 切换时打断时序）、`MindmapDisplay`（同理）。
- 与 demo 的关键差异：光雾改为 `inset: 0` 铺满容器 + `transform-origin: 50% 0` 缩放，不再写死 `--wave-size`（面板比 demo 卡片高，原尺寸盖不住）；额外加 `mask-image` 让雾向底部衰减，保证正文对比度。
- 流式光标用 `:is(p,li,h1,h2,h3):last-child::after`，再用 `:not(:last-child) 后代` 选择器关掉非文档序末尾的光标（否则列表末项和末段落各挂一个）。

验证方式：`demo` 里的 CSS 抽到临时 HTML，用 headless Chrome + 负 `animation-delay` + `paused` 把动画钉在指定进度截图核对。`tsc --noEmit` 与 `wxt build` 均通过。
